# 🎥 Screen Recording Web Application

A simple and lightweight **Screen Recording Web App** built using **HTML, CSS, and JavaScript**.  
This project allows users to record their screen directly from the browser and save the recording as a video file.  

---

## 🚀 Features
- Start, pause, and stop screen recording
- Save recorded video in **.webm** format
- Clean and responsive UI
- Works on modern browsers (Chrome, Edge, etc.)

---

## 🛠️ Tech Stack
- **HTML5** – Structure and layout  
- **CSS3** – Styling and responsiveness  
- **JavaScript (MediaRecorder API)** – Screen capture & recording functionality
